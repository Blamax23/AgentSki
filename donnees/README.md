# Données

`pistes.txt` : noms des pistes de descente du Grand Massif, une par ligne. Les trois premières viennent des documents du projet ;
les autres sont importées d'OpenStreetMap avec `scripts/importer_pistes_osm.py` (zone resserrée autour des cinq stations,
liaisons, accès et variantes écartés).

Source : © contributeurs OpenStreetMap, licence ODbL (https://www.openstreetmap.org/copyright). Les noms peuvent contenir des erreurs
ou des oublis : corrige le fichier à la main, une piste par ligne. Les pistes apprises au fil des entretiens vont dans
`data/pistes_apprises.txt`, qui n'est pas dans git.
